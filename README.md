# Windows Wi-Fi 一键优化脚本

单文件 BAT 脚本，用于 Windows 10/11 无线网卡优化：

- 自动将无线网卡「首选频带」设置为 **首选 5GHz 频带**
- 自动取消「允许计算机关闭此设备以节约电源」
- 自动重启无线网卡使设置生效
- 弹窗显示优化前后的 Wi-Fi 链路速率、频带、信道和信号强度对比

## 使用方法

1. 双击 `Windows-WiFi-OneClick-Optimizer.bat`
2. 在 UAC 弹窗中点击「是」
3. 等待网卡重启（Wi-Fi 会短暂断开）
4. 查看弹出的优化结果

## 说明

- 脚本会自动提权，无需手动进入设备管理器。
- 对比的是 Wi-Fi 协商链路速率，不是运营商宽带实测速度。
- 实际速度还取决于路由器、宽带套餐、距离和网络拥塞。
- 如果优化后仍连接 2.4GHz，通常是 5GHz 信号弱或路由器未启用 5GHz。
- 文件编码为 UTF-8（无 BOM），BAT 使用 CRLF 换行。

## 兼容性

适用于 Windows 10/11，使用系统自带的 PowerShell 5.1、NetAdapter 模块和 WMI，无需安装额外组件。
